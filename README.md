# XenoMenu

**A live desktop application with an arts style and interface inspired by the 1998 *Xenogears* menu display.**

## Features

- Live CPU / Memory / Storage / Battery as party HP gauges
- Original field-menu tones (cursor, confirm, cancel, open) — not ripped game audio
- Keyboard-first navigation and global hotkey
- **macOS Apple Silicon (arm64) only** — Intel Macs are not built
- Windows 11 secondary

## Building

```bash
npm install
npm start
npm run build:mac   # Apple Silicon DMG: XenoMenu-*-mac-silicon.dmg
npm run build:win
```
